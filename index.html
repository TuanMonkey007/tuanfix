macOS

⬇ Tải cho macOS

Cài đặt trên Windows

  1. Bấm Tải bộ cài Windows rồi mở file TuanFix-Setup.exe.
  2. Nếu Windows hiện “Windows protected your PC”: bấm More info → Run anyway (ứng dụng chưa mua chứng chỉ ký số nên Windows cảnh báo).
  3. Chọn thư mục cài → Install. Xong, mở Tuấn Fix từ Desktop.
  4. Khi bấm các nút sửa lỗi hệ thống, Windows sẽ hỏi quyền quản trị (UAC) — bấm Yes.

Cài đặt trên macOS

  1. Mở file .dmg, kéo Tuấn Fix vào Applications.
  2. Lần đầu mở: chuột phải vào app → Open → Open (do ứng dụng chưa ký số với Apple).
